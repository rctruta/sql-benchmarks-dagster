# scratch/

Local-only workspace. **Nothing here is committed** (except this README).

Drop drafts, throwaway notes, experiment doodles, or any Markdown you want to
keep beside the code but out of git. The repo ignores `scratch/*`, so it's a
safe place for work-in-progress that shouldn't ship.

(All *other* Markdown in the repo is tracked by default — there is no blanket
`*.md` ignore. If a doc belongs in the repo, just add it; if it's local, put it
here.)
